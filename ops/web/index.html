How it works

A fully-automated, long-only paper-trading system for the AI-infrastructure equity complex. It ingests industry writing, forms a machine thesis, ranks names mechanically, and executes on a fixed schedule — no human in the loop. Two engines have run this $100,000 paper account: the retired signal-eng (grey on the chart) and the current layercake (blue). Everything below is paper money; none of this is investment advice.

layercake — the current engine

Core idea: the AI build-out is a five-layer "cake", physical → value-capture — power (grid, generation, electrical gear), fabrication (foundries, semicap, materials), compute (accelerators & memory), infrastructure (datacenters, cooling, networking), and platform (hyperscalers & software). Baseline weights deliberately tilt toward the layers the Nasdaq underweights (power/fab/compute/infra) and away from platform's concentrated core. The universe is a curated ticker→layer map (~60 names); anything unmapped is ineligible.

Each run is a five-stage pipeline:

  1. Ingest — pulls supply- and demand-side writing (SemiAnalysis, Fabricated Knowledge, Stratechery, Platformer, Latent Space, Import AI), HuggingFace Daily Papers, and SEC 8-K filings for the mega-caps, into a local SQLite store.
  2. Thesis pass — an LLM (Gemini) reads the organized corpus and emits a layer tilt (how to shade each layer vs baseline), a market-regime label, and a written thesis. The tilt must sum to ~zero (reallocation, not leverage), is clamped to each layer's [8%, 35%] band, then renormalized so the five layer budgets sum to 100%.
  3. Momentum — within each layer, names are ranked by 12–1 momentum (the classic trailing-12-month return excluding the most recent month), and the top 3 are selected.
  4. Assemble — each layer's budget is split among its selected names, weighted by momentum and capped at 12% per name. Names with negative momentum are left in cash (strategy-driven cash), so the book can sit below 100% invested when conviction is thin.
  5. Execute — a weekly rhythm on the Alpaca paper account: recompute & persist the target daily (no trades), sell leg on Friday (close names that left the target, trim overweights), buy leg on Monday (fill deficits with the freed cash). Orders are notional, min $500, no leverage, cash-capped.

signal-eng — v1, retired (the grey era)

signal-eng ran this account before layercake. It used a daily LLM scorer plus a macro market-regime model to hold a book of mega-cap AI names (NVDA, MSFT, GOOGL, META, AMZN, AVGO, TSM, CEG, NRG …), turning scores into target weights and rebalancing daily whenever the book drifted past a set threshold from target. It also mirrored the book to a live brokerage (Interactive Brokers). It ran from account inception — Mar 24, 2026 ($100,000) — to the layercake migration on Jun 29, 2026, reaching about $116,835 (+16.8%) by the Jun 27 close (the grey curve). It was retired at the migration in favour of layercake's more disciplined, cash-aware, layer-budgeted approach.
